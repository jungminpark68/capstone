# 그림일기 장면 검증 프로토타입

## 실행

- Node.js 22 이상에서 `npm start` → `http://localhost:3000/verification`.
- API 없는 단일 파일: `verification-demo.html`을 브라우저로 열기.
- 재생성: `npm run build:verification-demo`.
- 수집 정보와 질문: [diary-data-and-questions.md](diary-data-and-questions.md).

## 체험

내용 일치·행동 주체 교환·인물 누락·가려진 행동의 예시 4종을 바꾸어 본다. **예시 판정 보기**는 사전 주석을 표시하며 실제 AI 추론이 아니다. 각 사실을 사람이 일치·불일치·판단 보류로 검토하고 **검토 결과 저장**을 누른다. 예시는 **예시 주석으로 채우기**도 가능하다.

**장면·필수 정보 편집**에서 날짜·장소·사람과 활동, 인물별 행동, 기억 단서 확인 상태를 바꿀 수 있다. 없음·모름·거절도 보관한다. 같은 장면 정보에서 매칭 정보·생성 조건·검증 사실을 만든다. 직접 올린 그림의 사람 검토와 요청문 내보내기는 API 없이 가능하다.

## 실제 생성과 AI 판정

`.env.example`을 참고해 서버 `.env`에 `DIARY_API_KEY`를 설정하고 다시 시작한다. 키를 브라우저나 Git에 넣지 않는다.

- `DIARY_IMAGE_MODEL`: 기본값 `gpt-image-2.5-sunburst`.
- `DIARY_VERIFY_MODEL`: 기본값 `gpt-4o-mini`.
- **이 조건으로 그림 생성**: 확인한 장면을 `/api/scene-illustration`으로 보내 서버가 필수 조건을 적용해 생성한다.
- **자체 모델로 판정하기**: 학습된 판정 모듈 서버를 실행하고 `DIARY_VERIFIER_URL`을 설정한다. 외부 판정 API 키 없이 실행한다.
- **범용 API로 비교하기**: 판정 방식에서 범용 API를 명시적으로 선택한다. 그림·장면·인물·사실을 API에 제공한다.

실제 API 버튼을 누르면 입력을 OpenAI로 전송하고 비용이 발생한다. 키 설정이 인증·모델 권한을 보장하지는 않는다. 단일 HTML은 네트워크 없이 체험하며 API 버튼을 활성화하지 않는다. 한국어 인코더 기반 판정기의 학습·서버 코드는 포함되어 있으나 실제 수집 자료의 학습 가중치는 아직 없다. 학습형 매칭·자동 그림 수정은 별도다. 수정 요청문을 만들어도 그림이 자동 수정되지는 않는다.

## 판정과 집계

- `supported`: 해당 사실을 그림에서 확인할 수 있음.
- `contradicted`: 명확한 충돌. 확실한 필수 인물·사물 누락도 포함.
- `uncertain`: 가림·모호함·기준 부족. 일치나 오류로 바꾸지 않음.

정확한 날짜·신원·가족관계는 외형만으로 추정하지 않는다. 선택 장면 밖의 하루 활동은 누락 오류로 처리하지 않는다.

예시·AI 생성 그림·출처 미확인 자료를 따로 집계한다. 업로드 자료의 생성 출처와 모델명은 사용자 제공이다.

- **확인된 오류 그림 비율** = 불일치가 하나 이상인 그림 / 모든 필수 항목을 사람이 검토한 그림.
- **보류만 남은 그림** = 불일치 없이 보류가 남은 그림. 전체 일치와 구분한다. 보류가 남아 있으면 오류 그림 비율은 확인된 오류의 최소 비율이다.
- **항목 불일치 비율** = 불일치 항목 / 사람이 검토한 전체 항목. JSON에 별도 포함한다.
- **모델–사람 판정 일치율** = 실제 자체 모델 또는 범용 API 예측과 사람의 3분류 판정이 같은 항목 / 둘 다 있는 항목. 생성 오류율과 다르며 예시 주석은 모델 예측에 포함하지 않는다.

이 표본을 모델 전체 오류율로 일반화하지 않는다. 정식 평가에는 독립적인 복수 검토와 불일치 조정이 필요하다. 사람 검토 중 AI 판정을 가리는 기능을 제공한다.

## 보관

검토 기록은 현재 탭 메모리에만 보관하며 기존 일기 저장소와 분리된다. 종료 전에 JSON을 내려받는다. 최대 24장, 업로드는 JPG·PNG·WebP 8MB 이하로 제한하며 최대 변 1400픽셀로 줄여 준비한다.

같은 그림·같은 장면을 다시 저장하면 기록을 갱신하고 표본 수를 늘리지 않는다. JSON에 그림, 확인한 장면, 매칭 정보, 생성 당시 조건·모델, 예측과 사람 주석의 출처, 학습 여부와 학습 범위를 보관한다. 예시·API는 자체 학습 완료로 표시하지 않는다. 통제 실험에서는 원본·수정본, 모델·설정·프롬프트와 참여자·사건을 구분해야 한다.

## 확인 범위

자동 테스트는 입력·생성 조건 전달·역할 교환·오류와 보류의 분모·기존 기능 회귀를 확인한다. 브라우저 테스트는 예시 4종·직접 업로드·사람 검토·기록 중복 방지·JSON·단일 HTML·모바일·모의 생성과 VLM 흐름을 확인한다. 실제 모델의 검출 성능이나 SCD 회상 효과를 측정한 실험은 아니다.
