## 전달하고 싶은 핵심

- 일상을 말로 기록하고, 관련 있는 과거 기록을 보며 다시 이야기하도록 돕는 앱입니다.

- 범용 ChatGPT가 비슷한 일을 할 수 없다고 주장하지 않습니다. 같은 조건에서 사실 일치·추가 입력·사용 부담을 비교합니다.

## 슬라이드별 근거·범위

### 1. 기억잇다
표지 그림·팀원·발표일은 업로드된 1조 PPT 기준. 가상 그림 예시이며 실제 사용자 자료가 아님. 프로젝트명은 기억잇다로 통일.

### 2. 일상의 깜빡함에서 시작했습니다
목표 요건 대응: 실제 제공된 팀 논의를 아이디어 묶음과 선정 기준으로 시각화. 새로운 사용자 조사나 공식 워크숍을 수행했다고 주장하지 않음. 부모님 경험은 주제 선정의 계기이며 SCD 진단 근거가 아님. 연령만으로 사용 능력을 가정하지 않음. 현실적 제한은 사용 부담·한 학기 개발 범위·검증 가능성, 공학적 제한은 AI 지연·위치 오차·권한과 동의로 명시.

### 3. 개인 경험과 익숙한 목소리
분석 요건 대응: 문헌을 통한 자료 수집→발견한 결과→서비스 적용 및 해석 범위. Felinto et al. 2025 DOI 10.1093/geronb/gbaf093, Souza et al. 2013 DOI 10.3766/jaaa.24.8.6. Dijkstra & Janssen 2016 DOI 10.1177/2158244016646412는 사람·장소·활동 단서와 경험 확인의 보조 참고자료로 참고문헌 문서에 수록.

### 4. 말하고, 보고, 다시 이야기합니다
합성 요건 대응: 사용자 흐름 설계와 기능 간 전달 관계. 화면은 팀원이 제공한 원본 보관함 캡처이며 실제 개인 기록이 아닌 가상 자료. 전체 가족 음성·GPS 연계까지 동작하는 통합 완료 화면이라는 의미가 아님.

### 5. 오늘의 이야기가 일기가 됩니다
제작 요건 대응: Node.js 체험 서버와 실제 브라우저에서 새로 캡처한 대화·글 초안 확인 화면. 유료 이미지 생성은 호출하지 않았고 글 초안을 그림 생성 완료 결과로 표시하지 않음. 하단 장소·시간·인물은 연결 데이터 설계를 설명하는 편집형 주석으로, 실제 화면에 구현된 필드나 현재 일기 저장 모델의 완료 상태를 보여주는 것이 아님.

### 6. 어떤 추억을 다시 꺼내줄까요?
분석 요건 대응: 팀원 모듈의 실행 사례를 그림과 연결 이유로 해석. 원본 자료의 2026-10-29 아들·손녀 호수공원 입력과 가상 과거 114개·노출 이력 없는 예시를 사용. 시간은 2026-09-29 수영장, 사람은 2026-10-23 손도장, 장소는 2026-10-23 호수공원. 이 작업에서 코드를 재실행한 결과나 사용자 만족도 측정으로 제시하지 않음. 시간·사람·장소별 최대 3개이며 1·3·12개월마다 하나씩 뽑는 방식이 아님. ±7일·점수·노출 감점은 현재 설계값이고 임상 최적값이 아님.

### 7. 기억나지 않아도 괜찮습니다
제작 요건 대응: 입력·질문·도움·종료 상태를 분리한 대화 진행 설계. 말풍선과 버튼은 흐름 설명을 위한 편집형 예시이며 실제 앱 캡처로 표시하지 않음. B 자료에는 회상 첫 질문 포함 최대 3문답, 불명확할 때 주제 선택 1회, 모르겠음·피로·쉬기에 마무리하는 규칙이 있음. 현재 경험 일기 대화는 별도 모듈이므로 모든 앱 대화가 최대 3문답이라는 뜻이 아님.

### 8. 말한 약속이 달력에 남습니다
제작 요건 대응: 독립 브라우저에서 실제 일정 추출·사용자 확인·달력 저장을 실행한 화면. 2026-11-05 기준 내일인 11월 6일 오후 1시·5시 병원 두 일정을 표시. 무료 체험 모드이며 실제 AI의 모든 표현 정확도를 검증한 자료가 아님. 화면 크기에 맞춰 달력과 일정 상세 영역을 각각 캡처하여 배치했음.

### 9. 친숙하게 듣고, 필요할 때 확인
합성 요건 대응: 음성 등록·합성·재생 서비스와 일정·위치·보호자 확인을 연결한 제작 가능한 설계. 이 화면은 연계 설계이며 실제 가족 음성 합성·알림 전송의 통합 완료 캡처가 아님. 음성 사용 동의·삭제·공유 범위, 위치 정확도·유예시간·배터리·권한은 설계 제약. 학술 연구의 실제 녹음 음성 결과를 합성 가족 음성 효과로 일반화하지 않음.

### 10. 기능은 이렇게 함께 움직입니다
합성 요건: 관련 기술의 목적과 한계를 조사·비교하여 역할을 선정하고 연결 가능한 설계를 제시. 제작 요건: JavaScript·HTML·CSS·Node.js·AI API·브라우저 저장을 사용한 핵심 웹 제작. B의 회상 검색·질문 선택은 API 없는 로컬 규칙이며 음성 인식·가족 음성·GPS 전체가 로컬이라는 뜻이 아님. 사용자는 알아야 할 필요가 없는 내부 코드·모듈명·점수 공식은 발표 본문에서 제외.

### 11. 오늘 기록이 다음 활동으로
분석 요건 대응: 문헌·팀 논의·오류 사례·실제 화면·자동 검사 기록·가상 추천 사례를 함께 활용하여 문제와 유용성을 검토. 숫자가 성능처럼 보이지 않도록 86개·11개 묶음·100개·114개를 본문에서 제외. 기존 핵심 웹 테스트 및 팀원 검사 기록은 필요 시 질문에 답할 근거이며 실사용자 임상 효과나 ChatGPT 대비 개선율로 제시하지 않음. 비교 실험과 실제 대상 사용성 평가의 완료 결과는 없음.
