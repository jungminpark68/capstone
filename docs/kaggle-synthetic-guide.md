# 기억잇다 · 자료 없는 Kaggle 합성 판정 실험

노트북 한 파일에 필요한 소스를 포함했습니다. Dataset 업로드, 앱 실행, API 키 준비 없이 실행합니다. Internet은 패키지와 공개 사전학습 인코더 다운로드에 사용합니다.

## 실행 순서

1. `memory-synthetic-v0.15.zip`을 풀고 `memory_connect_synthetic_kaggle.ipynb`를 찾습니다.
2. Kaggle의 Import Notebook으로 이 `.ipynb`를 불러옵니다.
3. GPU와 Internet을 켭니다.
4. 위에서부터 실행하거나 Run All을 누릅니다. 첫 실행에는 모델 다운로드가 있습니다.

기본값은 사건 30개 × 변형 11종 = **그림 330장, 사실 판정 2640개**입니다. 그림을 코드로 그리며 정답은 장면 구성·가림 규칙에서 계산합니다. 예측은 실제 BGE-M3·SigLIP2 특징으로 학습한 판정 모듈이 계산합니다.

## 만드는 케이스

| 케이스 | 변경하는 내용 |
|---|---|
| 정상 | 모든 기준 사실 유지 |
| 역할 교환 | 사람·사물을 유지하며 A/B의 행동 교환 |
| 인물 누락 | 한 인물과 그 인물이 사용하는 사물 제거 |
| 인물 추가 | 구별되는 세 번째 인물 추가 |
| 사물 누락 | 행동에 필요한 사물 제거 |
| 수량 오류 | 탁자 위 사과 수량 변경 |
| 배경 오류 | 공원·실내 배경 교환 |
| 좌우 오류 | A/B 위치 교환 |
| 색상 오류 | 사과 색 변경 |
| 인물 가림 | 인물과 행동 영역을 불투명 가림판으로 가림 |
| 사물 가림 | 사과와 수량 영역을 가림 |

가림은 불일치와 구분해 확인할 수 없는 항목에 판단 불가를 줍니다. 인물의 옷 색·행동·위치·크기와 사과 수량·색이 사건별로 달라집니다. 이미지 안에 정답이나 케이스 이름을 쓰지 않습니다. 라벨·케이스 종류·장면 그래프는 모델 입력에서 제외합니다.

같은 사건의 11종 변형을 같은 묶음에 넣고 학습/검증/시험을 나눕니다. 똑같은 이미지의 분할 누출도 검사합니다. 시험 결과로 체크포인트를 고르지 않고 검증 loss를 사용합니다.

## 비교와 출력

- **always-supported**: 항상 일치라고 답하는 명시적인 단순 기준선.
- **pooled**: 문장과 이미지 패치 평균 특징을 결합하는 학습 모델.
- **plain**: 문장–이미지 패치 어텐션 학습 모델.
- **relation**: plain에 같은 사실의 정상/오류 쌍 대조 손실을 추가한 모델.

기본적으로 세 학습 모델에 같은 클래스 가중치·자료·시드·배치를 적용합니다. 한국어와 그림 인코더는 고정하고 결합·판정 모듈만 학습합니다.

성능표 HTML/CSV/JSON, Macro-F1, 오류 검출률, 정상 통과·오경보·보류 비율, 혼동행렬, 유형별 결과를 저장합니다. 그림·규칙 정답·실제 예측을 나란히 표시하며 유형별 살펴보기는 오분류가 많은 사례를 우선 보여줍니다. 전체 성능은 모든 시험 자료로 계산합니다.

마지막 새 사례 셀에서 `CASE="role_swap"` 등을 바꾸어 새 그림을 판정할 수 있습니다. 표시할 모델은 `SHOW_METHOD="relation"`을 pooled/plain/relation으로 바꿉니다.

## 첫 설정 셀

```python
N_EVENTS = 30

```

빠른 연결 확인은 `N_EVENTS=6`, `EPOCHS=2`로 줄일 수 있습니다. 적은 사건으로 나온 성능은 매우 불안정합니다. 더 큰 실험은 자료 수와 시드를 늘리고 결과를 함께 봅니다.

재실행하면 기존 결과를 덮어쓰지 않고 실행 폴더에 `-02` 같은 번호를 붙입니다. 같은 사전학습 모델·그림·문장은 특징 캐시를 재사용합니다.

마지막 셀에서 다음과 같은 결과 파일을 만듭니다.

```text
/kaggle/working/memory-synthetic/synthetic-v1-results.zip
```

실제 경로는 출력된 `RUN` 이름을 확인합니다. ZIP에는 합성 그림·정답·학습 가중치·예측·성능표를 넣고 큰 인코더 캐시는 제외합니다.
