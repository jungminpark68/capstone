# 기억잇다 · 20장으로 시작하는 판정기 학습 전후 비교

이 묶음에는 생성 그림 20장, 정답 검토 화면, 소스를 포함한 Kaggle 학습·비교 노트북이 있습니다. 학습 가중치나 실제 성능 수치를 미리 넣지 않았습니다.

## 먼저 할 일: 정답 확인

1. ZIP 전체를 압축 해제합니다. 파일 하나만 따로 열면 그림 경로가 끊깁니다.
2. `01_review.html`을 Chrome 또는 Edge로 엽니다. 서버나 API 키가 필요하지 않습니다.
3. 검토자 ID를 적습니다. 예: team-01.
4. 그림마다 8개 사실을 실제 그림과 비교합니다. 일치/불일치/판단 불가 중 골라 주세요.
5. 학습·검증용 16장은 AI 초벌이 선택돼 있습니다. 틀린 항목은 수정합니다. 초벌은 정답이 아닙니다.
6. 시험용 4장은 초벌 답을 숨겼습니다. 모든 항목을 직접 고릅니다.
7. 직접 확인했다는 체크를 하고 **이 그림의 정답 확정 후 다음**을 누릅니다.
8. **확정 20 / 20장**이 되면 **검토 결과 JSON 받기**를 누릅니다. 파일명은 `memory-verifier-human-review.json`입니다.

중간에도 JSON으로 보관하고 **이전 검토 이어받기**로 복구할 수 있습니다. 브라우저 임시 보관은 기기·브라우저·파일 위치에 따라 달라지므로 내려받은 JSON을 함께 보관하세요. 선택을 고치면 그 그림은 다시 확정해야 합니다.

### v0.20.1 인물 표시 업데이트

사건 설명·판정 문장·초벌 설명을 '초록색 상의 할머니', '파란색 상의 손주'처럼 표시합니다. 기존 20장 표기에서 A는 어르신, B는 아이였고 문장이나 좌우 위치에 따라 바뀌는 이름은 아니었습니다. 새 화면은 그림별 인물 설명에서 호칭을 연결하며, 위치 조건은 별도로 판정합니다.

작은 업데이트 ZIP의 01_review.html만 기존 폴더에 덮어씁니다. source 폴더와 2번 노트북은 그대로 사용합니다. 자료 지문·그림·항목 ID가 같으므로 이전 검토 JSON도 '이전 검토 이어받기'로 가져올 수 있습니다.

## 판정 기준

- 일치: 그림에서 해당 사실을 확인할 수 있습니다.
- 불일치: 그림이 사실과 명확히 다릅니다. 필수 인물·사물이 명확히 빠진 경우도 포함합니다.
- 판단 불가: 가려짐, 모호한 행동, 불분명한 색 등으로 판단하기 어렵습니다.

그림을 만들 때 정상/오류를 의도했는지는 정답이 아닙니다. 인물–행동 연결, 실제 개수, 실제 색과 위치를 보세요. 학습에 판단 불가 예시가 필요하다는 이유로 명확한 그림의 정답을 바꾸면 안 됩니다.

## Kaggle에서 학습

1. Kaggle Notebook을 만들고 `02_train_compare_kaggle.ipynb`를 Import합니다.
2. Input에 이 묶음의 `source` 폴더와 내려받은 검토 JSON을 데이터셋으로 연결합니다. ZIP을 업로드했다면 실제 `source/pilot-source.json`과 그림들이 풀려 있는지 확인합니다.
3. GPU·Internet을 켭니다. T4 두 장의 메모리를 자동으로 합쳐 쓰는 노트북은 아닙니다.
4. 처음에는 설정을 바꾸지 말고 Run All을 실행합니다. 자료를 자동으로 찾지 못하면 SOURCE_PATH와 REVIEW_PATH에 Input의 실제 파일 경로를 적습니다.
5. 자료·이미지 지문과 사람 정답을 먼저 검사하고, 그다음 모델을 내려받아 학습합니다. 미완료 정답을 AI 초벌로 대신 채우지 않습니다.
6. 기본 비교는 **같은 Qwen/Qwen3-VL-4B-Instruct의 추가 학습 전 / 일반 LoRA 학습 후**입니다. 같은 프롬프트·기반 가중치 revision·양자화·출력층을 사용합니다.
7. 먼저 검증셋 결과가 나옵니다. 마지막 결과 보관 셀에서 결과 ZIP을 받아 전달해 주세요. `development-comparison.html/.csv/.json`과 `history.json`을 보고 학습 상태와 다음 설정을 분석할 수 있습니다.
8. 설정이 정해지면 **5. 최종 예비 시험** 코드 셀의 첫 줄 `RUN_FINAL_TEST=False`만 True로 바꾸고 **그 셀만** 실행합니다. 이어 마지막 보관 셀을 다시 실행합니다.

실제 GPU 학습 시간이나 정확도를 사전에 보장하지 않습니다. API 요금은 없으며 Kaggle의 GPU·디스크 할당과 공개 모델 다운로드가 필요합니다. 이 클라우드 환경에는 GPU가 없어 실제 Kaggle 학습은 아직 실행하지 않았습니다.

## 기본 설정과 조정

- EPOCHS=2: 최대 반복 횟수. 각 epoch 중 검증 Macro-F1이 가장 높은 가중치를 선택합니다.
- LEARNING_RATE=1e-4, LORA_RANK=16, BATCH_SIZE=2, ACCUMULATION=4.
- FOUR_BIT=True, MAX_PIXELS=200704: 학습 전후에 동일하게 적용합니다.
- METHODS=["plain"]: 학습 전후 2개 조건입니다. 이후 ["plain","relation"]으로 바꾸면 오류 그림 쌍 대조 손실 조건을 추가할 수 있습니다. 같은 사실에 대한 일치/불일치 그림 쌍이 필요합니다.

튜닝은 검증셋으로 합니다. 시험 결과를 본 뒤 추가 튜닝한다면 새로운 독립 시험 자료가 필요합니다. GPU 메모리가 부족하면 MAX_PIXELS를 낮춘 새 실험을 사용하고, 비교 조건들의 해상도는 같게 유지합니다. plain만 학습할 때는 BATCH_SIZE=1도 가능하며 relation을 포함하면 2 이상이 필요합니다.

사람 검토 결과에 학습용 세 종류 정답 중 하나가 없으면 중단합니다. 그 경우 실제로 해당되는 그림을 추가 수집·검토한 새 자료 버전이 필요합니다. 현재 20장의 라벨을 억지로 바꾸지 않습니다.

## 이 20장의 범위

20장·160개 사실·10개 사건입니다. 사건별 두 그림을 묶어 학습 12장/6사건, 검증 4장/2사건, 시험 4장/2사건으로 고정했습니다. 같은 이미지나 사건을 여러 분할에 섞지 않습니다.

그림은 채팅 이미지 생성 도구로 만들었으며 도구가 공개한 정확한 모델 ID는 없습니다. 앱의 이미지 API 모델과 동일하다고 주장하지 않습니다. 이전에 20장 모두의 AI 초벌이 만들어졌으므로 이번 시험 화면에서 답을 숨겼다는 이유만으로 새 독립 평가 자료가 되는 것은 아닙니다. 본 묶음은 흐름 확인과 예비 비교용입니다.

사람 한 명의 검토는 확정된 다수 검토자 정답이 아닙니다. 정식 보고에는 추가 자료·독립 재검토가 필요하며, 4장 시험의 점수를 일반 성능이나 생성 모델의 자연 오류율, 인지 개선 효과로 해석하지 않습니다.
